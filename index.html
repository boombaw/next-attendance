INTRODUCTION

Welcome to Absensi Yuk

First of all, thank you for purchasing Absensi Yuk. This template is a high-performance attendance and workforce management system built with Next.js 14+ (App Router), Tailwind CSS, and TypeScript.

This documentation aims to help you set up the project and understand its architecture for faster development.

Core Features

Dual Role System

Built-in views for both Employee and Supervisor roles.

Modern Tech Stack

Utilizing Next.js App Router for optimal performance.

Dark Mode Ready

Fully compatible with light and dark color schemes.

Fully Responsive

Looks great on mobile, tablet, and desktop screens.

Folder Structure

Absensi Yuk follows a modular architecture for easy maintenance:

src/
├── app/             # Application routes & layouts (Next.js 14+)
├── components/      # Reusable UI components (Shared UI)
├── contexts/        # React Context API (Auth, User State)
├── hooks/           # Custom React hooks
├── lib/             # Third-party configs & helper functions
├── styles/          # Global styles & Tailwind entry
└── types/           # TypeScript interfaces & types

Installation Guide

Follow these steps to run the project locally:

1. Install Dependencies

Open your terminal in the project root directory and run:

npm install

2. Run Development Server

npm run dev

The application will be available at http://localhost:3000.

Customization

Changing Brand Colors

You can easily modify the primary colors in tailwind.config.ts. The template uses Tailwind's utility-first approach.

Iconography

This project uses Material Symbols Outlined. To change an icon:

<span className="material-symbols-outlined">settings</span>

Browse icons at: fonts.google.com/icons

Deployment

This template is highly optimized for Vercel, but can be deployed on any host that supports Node.js.

  1. Push your code to a Git repository (GitHub/GitLab).
  2. Connect your repository to Vercel.
  3. Vercel will automatically detect Next.js settings.
  4. Click Deploy.
